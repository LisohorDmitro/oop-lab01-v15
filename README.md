Варіант 15. Поле first — ціле додатнє число, тривалість телефонної розмови у хвилинах; поле second — дробове додатнє число, вартість однієї хвилини в гривнях. Реалізувати метод cost() для обчислення загальної вартості розмови. Обов’язкові Init() з перевіркою аргументів, Read() та Display().

## Збирання і запуск у Windows

Потрібен GCC MinGW-w64 з підтримкою C++14. Додайте каталог `bin` компілятора до `PATH` або передайте його скрипту через параметр `-CompilerDirectory`.

```powershell
.\build.ps1
Get-Content .\input.txt | .\lab01.exe
```

Команди збирання

```text
g++ -std=c++14 -O2 -Wall -Wextra -pedantic -static-libgcc -static-libstdc++ main.cpp -o lab01.exe
```

У `input.txt` збережені тестові вхідні дані, а в `expected_output.txt` — вивід перевіреного запуску.
